# All-Permutations

A console-based project of a Permutation Generator algorithm performed on a given word. It is written in Python, Java, and C++ to allow users to compare its performance in these three programming languages.

A threaded version of the C++ program is also included.

## What is a Permutation Generator?

A permutation generator is an algorithm that lists every possible order for a group of items. In the case of this project, the items that are being used for this process are letters from a user-given word.

## How the algorithm works

The algorithm begins by prompting the user to enter a word of their choice and calculates the number of permutations that can be produced using the word, factoring in repeated letters before starting the permutation process. It then starts to generate a permutation of the word provided and checks whether it has been discovered before or not. The algorithm ends when all unique permutations have been discovered.
